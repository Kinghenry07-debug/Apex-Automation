# 🤖 Apex Automation Systems — Industrial Robotics & Engineering Portal

An enterprise-grade B2B web portal designed for industrial automation companies, robotics integrators, and smart factory engineering solutions.

> ⚠️ **Disclaimer:** This project is an enterprise concept developed strictly for **portfolio showcase and demonstration purposes**. All business names, phone numbers, and addresses used are placeholders.

## 🚀 Live Demo
🔗 **[https://apex-automation.vercel.app](https://apex-automation-orpin.vercel.app/)**

---

## ✨ Key Features
- 📊 **Interactive ROI Calculator:** Built-in savings widget calculating estimated annual automation ROI based on factory workforce and shifts.
- 📑 **Capability Breakdown Tabs:** Interactive tab switching between Robotic Cells, PLC/SCADA Programming, and Vision Systems.
- 🎥 **Video Background Integration:** High-impact hero section highlighting robotic arm operations.
- ⚙️ **Edge Gear & Winch Navigation:** Dynamic scrolling gear RPM indicator with harpoon cable ascent mechanism and plant SCADA live telemetry ticker.
- 📝 **Feasibility Audit Form:** Enterprise lead form with persistent single-submission limit and Formspree integration for consultation requests.
- 🛡️ **Trust & Certification Badges:** Metric counter bars featuring ISO compliance and factory uptime stats.

---

## 🛠️ Tech Stack
- **Frontend:** React 18, TypeScript, Tailwind CSS, Vite, Lucide Icons
- **Form Engine:** Formspree API
- **State & Persistence:** Client-side LocalStorage & Web Audio API Synthesizer
